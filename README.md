# Proxyshop Plugin
I doubt they are working perfectly, but here are two LCARS templates for Proxyshop.

## Usage Guide
1. Create a new folder in `/Proxyshop/plugins` and name it **KarbonatErol**. Extract the contents of this repository into that folder.
2. Install the font in the `/fonts` folder.
3. Templates are already included, so you can start creating (this may not be how Proxyshop works, I'll fix it in the future if that's the case).

## NOTE: The set symbol

The current version of Proxyshop doesn't have the Star Trek set symbol. I made one myself and it can be found in this repository (symbols.zip), however, if you update Proxyshop it will be overwritten. I assume this will stop being a problem when Proxyshop adds that symbol (which should be soon). Just unzip the zip file into `/src/img` folder of your Proxyshop installation.
